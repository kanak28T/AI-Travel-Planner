# 🌏 AI Travel Planner

An AI-powered travel planning app that helps users discover destinations 
and generate personalized itineraries.

## Features
- Generate AI-driven travel itineraries
- Explore cities and tourist destinations  
- Save and manage your trips

## Tech Stack
- React + Vite
- Tailwind CSS + Radix UI
- TanStack Query
- AI API integration

## Getting Started
```bash
npm install
npm run dev
```
